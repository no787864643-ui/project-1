# Assets Directory

You can place your client's custom imagery here:
- `logo.png` / `logo.svg` for the brand logo.
- Product images (e.g. `product-1.jpg`, `product-2.jpg`).
- Lookbook or banner photos.

To reference any local image in `js/products.js` or `index.html`, use relative paths like:
`assets/my-image.jpg`
